# 实验二设计与答辩说明

## 模块做什么

程序将 MNIST 的 `28x28` 灰度图像按行转换成长度为 28 的序列。每个时间步读取一行
28 个像素，基础 RNN 依次更新隐藏状态，最后用第 28 个时间步的输出完成 0 到 9 十分类。

## 张量形状

| 阶段 | 张量形状 |
| --- | --- |
| DataLoader 输出 | `[batch, 1, 28, 28]` |
| 去掉通道维度 | `[batch, 28, 28]` |
| RNN 全部时间步输出 | `[batch, 28, hidden_size]` |
| 最后时间步输出 | `[batch, hidden_size]` |
| 分类层输出 | `[batch, 10]` |

## 为什么这样设计

RNN 擅长处理有先后顺序的序列。把图片从上到下逐行读取，可以把二维图片转成序列，
同时保留相邻行之间的结构关系。最后一个隐藏状态已经接收过前 27 行和当前第 28 行，
因此可作为整张图片的序列表示。

## 隐藏维度的影响

隐藏维度越大，隐藏状态可存储的信息更多，模型参数量和计算开销也更大。它可能提高
准确率，但也可能带来收益递减或过拟合。本实验只改变 `hidden_size=64/128`，其余条件
保持一致，用实际结果判断精度与效率之间的取舍。

## 老师可能会问

**为什么不用 CNN 识别 MNIST？**

CNN 通常更适合图片，但本实验目的是学习 RNN。按行把图片转换成序列后，仍可用 RNN
完成分类，并直观展示时间步和隐藏状态的作用。

**隐藏状态是什么？**

它是 RNN 在当前时间步保存的历史信息摘要。当前行输入和上一时间步隐藏状态共同产生
新的隐藏状态，再传给下一行。

**基础 RNN 有什么不足？**

序列较长时，反向传播可能出现梯度消失或爆炸，难以记住很早的信息。LSTM 通过门控
结构改善长期依赖问题。本实验还使用梯度裁剪降低梯度爆炸风险。
