# 07 卷积核对比实验结果分析

## 1. 本章核心问题

比较 `3x3` 和 `5x5` 卷积核时，你不能只说“谁准确率高”。

你要同时分析：

- 准确率。
- 参数量。
- 训练时间。
- 吞吐量。
- 泛化差距。
- 为什么会这样。

## 2. 控制变量

两组实验唯一主动改变的是：

```text
卷积核大小：3x3 vs 5x5
```

其他条件保持一致：

| 参数 | 值 |
| --- | --- |
| 输入尺寸 | 224x224 |
| 卷积块数量 | 4 |
| Batch Size | 32 |
| Epoch | 10 |
| 优化器 | Adam |
| 学习率 | 0.001 |
| Dropout | 0.3 |
| 数据增强 | 开启 |
| 随机种子 | 42 |
| DataLoader Workers | 4 |
| 训练设备 | RTX 4060 Laptop GPU |

这叫控制变量实验。

答辩时一定要强调“只改变一个变量”。

## 3. 结果表

| 指标 | 3x3 | 5x5 |
| --- | ---: | ---: |
| 最佳 Epoch | 9 | 9 |
| 最佳验证 Accuracy | 93.96% | 95.16% |
| 独立测试 Accuracy | 94.02% | 95.05% |
| 可训练参数量 | 427,174 | 1,116,838 |
| 总训练时间 | 1,560.47 秒 | 2,183.73 秒 |
| 平均每 Epoch | 156.02 秒 | 218.33 秒 |
| 训练吞吐量 | 450.47 张/秒 | 321.90 张/秒 |
| 验证-测试泛化差距 | 0.063 个百分点 | 0.118 个百分点 |

## 4. 准确率怎么解释

`5x5` 测试准确率：

```text
95.05%
```

`3x3` 测试准确率：

```text
94.02%
```

提升：

```text
1.02 个百分点
```

可能原因：

1. 植物病害的判别往往依赖病斑及周围纹理。
2. `5x5` 卷积核一次能看到更大局部区域。
3. 更大的局部感受野可能帮助模型捕捉病斑整体形态。

## 5. 参数量怎么解释

参数量：

```text
3x3: 427,174
5x5: 1,116,838
```

`5x5` 是 `3x3` 的约 2.61 倍。

原因是卷积参数量和卷积核面积成正比：

```text
3x3 面积 = 9
5x5 面积 = 25
```

在通道数相同的情况下，卷积核越大，权重越多。

## 6. 训练时间怎么解释

平均每 Epoch：

```text
3x3: 156.02 秒
5x5: 218.33 秒
```

`5x5` 增加了约 39.94%。

原因：

- 卷积核面积更大。
- 每个输出位置需要更多乘加运算。
- 参数更多，计算和内存访问成本更高。

## 7. 吞吐量怎么解释

吞吐量是每秒处理多少张图片。

```text
3x3: 450.47 张/秒
5x5: 321.90 张/秒
```

`5x5` 吞吐量下降约 28.54%。

这说明它虽然准确率更高，但训练效率更低。

## 8. 泛化差距怎么解释

本项目定义：

```text
泛化差距 = |最佳验证 Accuracy - 测试 Accuracy|
```

两组都小于 0.12 个百分点。

这说明：

- 验证集选出的最佳模型在测试集上表现稳定。
- 没有明显出现验证好、测试差的情况。

## 9. 正确结论怎么说

不要说：

> `5x5` 一定比 `3x3` 好。

应该说：

> 在当前数据集、模型结构和训练配置下，`5x5` 卷积核取得了更高的验证和测试准确率，说明较大的局部感受野对植物病害纹理识别有帮助。但它的参数量和训练时间也明显增加，因此需要在准确率和计算成本之间权衡。

## 10. 如果老师问“为什么不多跑几次”

回答：

> 更严谨的实验应该使用多个随机种子重复训练，并报告均值和标准差。本实验作为课程实验，重点展示控制变量、训练流程和结果分析，因此完成了一组固定随机种子下的对比。
