# 08 CNN 与 RNN 对比

## 1. 为什么要单独比较

你的两个实验正好分别使用 CNN 和 RNN。

老师很可能问：

> CNN 和 RNN 有什么区别？

你必须能讲清楚。

## 2. 核心区别

| 对比点 | CNN | RNN |
| --- | --- | --- |
| 擅长数据 | 图像、空间结构 | 序列、时间依赖 |
| 核心机制 | 卷积核提取局部特征 | 隐藏状态传递历史信息 |
| 输入特点 | 同时看局部二维区域 | 按时间步逐个读取 |
| 本项目任务 | 植物病害图片分类 | MNIST 按行序列分类 |
| 主要概念 | 卷积核、通道、池化、感受野 | 时间步、隐藏状态、序列长度 |

## 3. CNN 怎么看图片

CNN 直接在二维图片上滑动卷积核。
对应文件：`experiment_1_cnn/src/models.py`

对应代码片段：CNN 的二维卷积使用 `nn.Conv2d`。

```python
nn.Conv2d(in_channels, out_channels, kernel_size=conv_kernel_size, padding=padding)
```

例如 `3x3` 卷积核一次看一个局部小块。

它天然适合提取：

- 边缘。
- 纹理。
- 形状。
- 局部空间关系。

所以 CNN 更适合图像分类。

## 4. RNN 怎么看 MNIST

RNN 不直接看二维小块。

本实验把 MNIST 按行展开：

```text
第 1 行 -> 第 2 行 -> ... -> 第 28 行
```

RNN 通过隐藏状态把前面行的信息传到后面。
对应文件：`experiment_2_rnn/src/models.py`

对应代码片段：RNN 读入 `[B, 28, 28]` 序列，并取最后时间步分类。

```python
sequence = images.squeeze(1)
outputs, _ = self.rnn(sequence)
final_output = outputs[:, -1, :]
```

它更强调顺序关系。

## 5. 为什么 MNIST 用 RNN 也能做

虽然 CNN 更适合图片，但 MNIST 很简单：

- 图片小。
- 数字居中。
- 序列长度只有 28。
- 按行仍能保留很多结构。

所以基础 RNN 可以达到不错准确率。

但如果是复杂自然图像，CNN 通常更合理。

## 6. 答辩回答模板

如果老师问：

> 为什么实验二不用 CNN？

可以答：

> CNN 确实更适合图像，MNIST 用 CNN 通常效果也很好。但实验二的目标是学习 RNN 的序列建模思想，所以我把 MNIST 图片按行转成序列。这样可以直观展示时间步、隐藏状态和隐藏维度的作用。

如果老师问：

> CNN 和 RNN 最大区别是什么？

可以答：

> CNN 通过卷积核提取空间局部特征，适合图像；RNN 通过隐藏状态在时间步之间传递历史信息，适合序列。

## 7. 两个实验联系起来怎么讲

你可以这样总结：

> 实验一体现了 CNN 在图像空间特征提取上的优势，重点关注卷积核大小对植物病害分类的影响。实验二体现了 RNN 对序列数据的建模方式，把 MNIST 按行转换成序列，重点观察隐藏状态维度对分类效果的影响。两个实验分别对应深度学习中图像建模和序列建模的基本思想。
