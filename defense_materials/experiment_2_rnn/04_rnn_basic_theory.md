# 04 RNN 基础知识

## 1. RNN 是什么

RNN 全称 Recurrent Neural Network，中文是循环神经网络。

它适合处理序列数据，例如：

- 文本。
- 语音。
- 时间序列。
- 按行展开后的图片。

RNN 的特点是：

> 当前时间步的输出不仅取决于当前输入，还取决于之前时间步传来的隐藏状态。

## 2. 时间步是什么

时间步是序列中的一个位置。

在本实验中：

```text
时间步 1 = 图片第 1 行
时间步 2 = 图片第 2 行
...
时间步 28 = 图片第 28 行
```

## 3. 当前输入是什么

每个时间步输入一行像素：

```text
x_t: [B, 28]
```

其中 `t` 表示第几个时间步。

## 4. 隐藏状态是什么

隐藏状态可以理解成模型的“记忆”。

第 t 个时间步的隐藏状态记作：

```text
h_t
```

它由两部分决定：

```text
当前输入 x_t
上一个时间步隐藏状态 h_{t-1}
```

直观理解：

```text
h_t = 当前看到的信息 + 过去记住的信息
```

## 5. 为什么隐藏状态重要

如果只看当前一行，模型很难判断完整数字。

例如只看数字 8 的某一行，可能和 0、3、9 的某些行相似。

隐藏状态能把前面行的信息保留下来，使模型逐渐形成整体判断。

## 6. hidden_size 是什么

`hidden_size` 是隐藏状态向量的维度。

例如：

```text
hidden_size = 64
```

表示每个时间步用 64 个数保存历史信息。

```text
hidden_size = 128
```

表示用 128 个数保存历史信息。

维度越大：

- 表达能力可能更强。
- 能保存的信息更多。
- 参数量也更多。
- 计算成本可能更高。

## 7. RNN 输出是什么

PyTorch 的 `nn.RNN` 返回：

```python
outputs, hidden = self.rnn(sequence)
```

`outputs` 包含所有时间步的输出：

```text
[B, 28, hidden_size]
```

`hidden` 是最后的隐藏状态。

本项目使用 `outputs[:, -1, :]` 取最后时间步。

## 8. 为什么用最后一个时间步分类

最后一个时间步读完了整张图片。

理论上，它已经融合了前面 27 行和第 28 行的信息。

所以可以用最后时间步的输出作为整张图片的表示。

## 9. 基础 RNN 的问题

基础 RNN 在长序列中可能出现：

- 梯度消失。
- 梯度爆炸。
- 难以记住很早的信息。

本实验序列长度只有 28，不算很长，所以基础 RNN 也能工作。

但是更复杂任务通常会使用 LSTM 或 GRU。

## 10. LSTM 为什么改进 RNN

LSTM 增加门控机制。

它会学习：

- 哪些旧信息应该保留。
- 哪些新信息应该写入。
- 哪些信息应该输出。

因此 LSTM 更适合长序列和长期依赖。
