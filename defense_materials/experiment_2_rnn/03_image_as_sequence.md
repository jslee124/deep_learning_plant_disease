# 03 图片如何转换成序列

## 1. 本章是实验二最关键的理解点

RNN 原本处理序列。

MNIST 是图片。

所以必须解释清楚：

> 为什么图片能送进 RNN？

答案是：把图片按行看成序列。

## 2. 原始图片形状

DataLoader 输出：

```text
[B, 1, 28, 28]
```

其中：

- `B` 是 batch size。
- `1` 是灰度通道。
- `28x28` 是图片高宽。

## 3. squeeze(1) 做什么

模型代码：

```python
sequence = images.squeeze(1)
```

这一步把通道维度去掉：

```text
[B, 1, 28, 28] -> [B, 28, 28]
```

因为 MNIST 只有 1 个灰度通道，去掉这个维度不会丢失信息。

## 4. `[B, 28, 28]` 怎么理解

对 RNN 来说，输入格式是：

```text
[batch, sequence_length, input_size]
```

所以：

```text
[B, 28, 28]
```

表示：

- `B`：一个 batch 中有多少张图片。
- 第一个 `28`：序列长度，也就是 28 个时间步。
- 第二个 `28`：每个时间步输入 28 个像素。

## 5. 按行读取是什么意思

一张 `28x28` 图片可以看作 28 行。

每一行有 28 个像素。

RNN 读取顺序：

```text
时间步 1：第 1 行 28 个像素
时间步 2：第 2 行 28 个像素
时间步 3：第 3 行 28 个像素
...
时间步 28：第 28 行 28 个像素
```

这样，二维图片就被转换成了一维序列。

## 6. 为什么按行仍然有意义

手写数字从上到下有结构。

例如数字 8：

- 上面可能是上半圆。
- 中间可能收窄。
- 下面可能是下半圆。

RNN 逐行读取时，隐藏状态可以保存前面行的信息，逐步形成对整个数字形状的理解。

## 7. 这种方法的局限

按行转换会损失一部分二维空间直觉。

CNN 可以直接看局部二维区域，例如 `3x3` 小块。

RNN 按行读取时，更强调行与行之间的顺序关系。

所以：

```text
这个实验是为了学习 RNN，不是说 RNN 是图片分类最佳选择。
```

## 8. 你要能现场讲的一段话

> MNIST 原始输入是 `[B, 1, 28, 28]`。因为它只有一个灰度通道，所以我用 `squeeze(1)` 去掉通道维度，得到 `[B, 28, 28]`。对 RNN 来说，这表示序列长度为 28，每个时间步输入一行 28 个像素。RNN 从上到下逐行读取图片，并用隐藏状态保存已经读取过的行的信息。
