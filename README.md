# 深度学习课程项目

本仓库将平时实验和期末课程设计分开管理：

```text
deep_learning_plant_disease/
├── data/                    # 各任务共用的数据集，不提交 Git
├── experiment_1_cnn/        # 平时实验一：卷积神经网络
├── experiment_2_rnn/        # 平时实验二：循环神经网络
├── course_design/           # 期末课程设计
├── reports/                 # 两类报告
└── AGENT.md                 # 项目目标与协作规范
```

当前正在进行的是 [实验一 CNN](experiment_1_cnn/README.md)。

## 当前进度

- 课程设计：已建立独立目录，待平时实验完成后继续深化。

## 数据说明

大型数据集统一保存在根目录 `data/`。各实验通过配置或命令行参数读取该目录，
避免复制数据，也不会在不同任务之间共享模型和输出结果。
