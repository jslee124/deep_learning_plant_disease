# 深度学习课程项目

本仓库将平时实验和期末课程设计分开管理：

```text
deep_learning_plant_disease/
├── data/                    # 各任务共用的数据集，不提交 Git
├── experiment_1_cnn/        # 平时实验一：卷积神经网络
├── experiment_2_rnn/        # 平时实验二：循环神经网络
├── course_design/           # 期末课程设计
├── reports/                 # 两类报告
└── AGENT.md                 # 项目目标与协作规范
```

两个平时实验的正式训练已完成，课程设计已扩展到卷积核、卷积层数和 ResNet18
迁移学习对比。

## 当前进度

- 实验一：完成 `3x3/5x5` 卷积核对比和卷积特征图可视化。
- 实验二：完成 MNIST 基础 RNN 和隐藏维度 `64/128` 对比。
- 平时报告：完成报告正文和独立源码提交目录。
- 课程设计：完成 3/4 卷积块、`3x3/5x5` 卷积核及 ResNet18 迁移学习对比。

## 数据说明

大型数据集统一保存在根目录 `data/`。各实验通过配置或命令行参数读取该目录，
避免复制数据，也不会在不同任务之间共享模型和输出结果。
