# 实验一：基于卷积神经网络的植物病害图像分类

## 1. 实验题目与目的

本实验使用 PyTorch 自行搭建 CNN，对 38 类植物叶片健康状态和病害类型进行分类。
实验目的是掌握图像读取、卷积特征提取、训练、验证、独立测试和结果可视化流程，并在
其他条件相同的情况下比较 `3x3` 与 `5x5` 卷积核对准确率、参数量和训练效率的影响。

## 2. 设计思路

输入为 `3x224x224` RGB 图片。网络包含 4 个卷积块，通道数依次为
32、64、128、256。每个卷积后使用 BatchNorm 和 ReLU，前三个卷积块后使用最大池化。
最后使用自适应平均池化、全连接层和 Dropout 输出 38 个类别得分。

训练集用于更新参数；Kaggle 原验证集按类别和固定随机种子拆成验证集与独立测试集。
验证集选择最佳模型，测试集只做最终评价。损失函数为 CrossEntropyLoss，优化器为
Adam。训练期间保存最佳模型、逐轮日志、Loss/Accuracy 曲线和混淆矩阵。

## 3. 主要参数

| 参数 | 数值 |
| --- | --- |
| 输入尺寸 | 224x224 |
| Epoch | 10 |
| Batch Size | 32 |
| 学习率 | 0.001 |
| 优化器 | Adam |
| Dropout | 0.3 |
| 随机种子 | 42 |
| 卷积块数量 | 4 |
| 对比变量 | 卷积核 3x3 / 5x5 |
| 训练设备 | NVIDIA GeForce RTX 4060 Laptop GPU |

## 4. 实验结果

| 指标 | 3x3 | 5x5 |
| --- | ---: | ---: |
| 最佳验证 Accuracy | 93.96% | 95.16% |
| 独立测试 Accuracy | 94.02% | 95.05% |
| 参数量 | 427,174 | 1,116,838 |
| 总训练时间 | 1,560.47 秒 | 2,183.73 秒 |
| 平均每 Epoch | 156.02 秒 | 218.33 秒 |
| 吞吐量 | 450.47 张/秒 | 321.90 张/秒 |
| 验证-测试差距 | 0.063 pp | 0.118 pp |

`5x5` 测试准确率提高 1.02 个百分点，但参数量为 `3x3` 的 2.61 倍，平均每 Epoch
时间增加 39.94%，吞吐量下降 28.54%。这说明较大卷积核在本数据集上有利于同时观察
病斑和周围纹理，但准确率提升伴随明显计算成本。

![图 1 CNN 卷积核对比结果](../../experiment_1_cnn/outputs/comparisons/cnn_kernel_3x3_baseline_v2_vs_cnn_kernel_5x5_comparison/comparison.png)

图 1 汇总了两种卷积核的准确率、参数量、训练时间和验证-测试差距。所有数值均来自
对应实验目录中的 `final_result.json`。

## 5. 卷积特征图分析

第一层特征图仍保留叶缘、叶脉和病斑等局部纹理。经过池化和更深卷积后，特征图空间
尺寸从 `224x224` 逐步降到 `28x28`，响应逐渐集中在叶片轮廓和具有分类作用的病害
区域。浅层主要提取边缘和纹理，深层将这些低级特征组合成更抽象的类别特征。

![图 2 3x3 CNN 四层卷积特征图](../../experiment_1_cnn/outputs/runs/cnn_kernel_3x3_baseline_v2/figures/feature_maps_sample_0.png)

图 2 展示同一输入样本在四个卷积块后的部分通道响应。随着网络加深，特征图分辨率
降低、语义抽象程度提高。

## 6. 实验总结

本实验掌握了 CNN 各层作用、完整训练评价流程和单变量对比方法。实验表明不能只根据
Accuracy 判断模型优劣，还应同时考虑参数量、时间、吞吐量和泛化稳定性。

# 实验二：基于循环神经网络的 MNIST 手写数字分类

## 1. 实验题目与目的

本实验将 MNIST 图片按行转换为序列，使用 PyTorch 自行搭建基础 RNN 完成 0 到 9
十分类。实验目的是理解时间步、隐藏状态和序列分类，并比较隐藏维度 64 与 128 对模型
容量、准确率和训练效率的影响。

## 2. 设计思路

原图片形状为 `[batch,1,28,28]`，去掉灰度通道后得到 `[batch,28,28]`。序列长度
为 28，每个时间步输入一行 28 个像素。RNN 输出所有时间步的隐藏表示，取最后一个
时间步 `[batch,hidden_size]` 输入全连接层，得到 `[batch,10]` 类别得分。

MNIST 官方 60,000 个训练样本使用随机种子 42 固定拆分为 54,000 个训练样本和
6,000 个验证样本，官方 10,000 个测试样本保持独立。使用 CrossEntropyLoss、Adam
和梯度裁剪完成训练。

## 3. 主要参数

| 参数 | 数值 |
| --- | --- |
| 序列长度 | 28 |
| 每步输入维度 | 28 |
| RNN 层数 | 1 |
| Epoch | 10 |
| Batch Size | 128 |
| 学习率 | 0.001 |
| 优化器 | Adam |
| 随机种子 | 42 |
| 对比变量 | hidden size 64 / 128 |
| 训练设备 | NVIDIA GeForce RTX 4060 Laptop GPU |

## 4. 实验结果

| 指标 | hidden=64 | hidden=128 |
| --- | ---: | ---: |
| 最佳验证 Accuracy | 94.18% | 96.88% |
| 独立测试 Accuracy | 94.34% | 97.07% |
| 测试 Loss | 0.2023 | 0.1124 |
| 参数量 | 6,666 | 21,514 |
| 总训练时间 | 201.01 秒 | 165.34 秒 |
| 平均每 Epoch | 19.90 秒 | 16.52 秒 |

隐藏维度增加后测试 Accuracy 提高 2.73 个百分点，说明 128 维隐藏状态能保存更丰富的
笔画和行间结构信息。参数量增加到 3.23 倍，但模型总量仍较小。128 维实验实测时间
更短，可能受到首次运行下载、磁盘缓存和 CUDA 预热影响，不能据此认为更大的 RNN
天然更快；效率结论应通过多次重复实验进一步验证。

![图 3 RNN 隐藏维度对比结果](../../experiment_2_rnn/outputs/comparisons/rnn_hidden_64_baseline_vs_rnn_hidden_128_comparison/comparison.png)

![图 4 hidden=128 的 MNIST 预测示例](../../experiment_2_rnn/outputs/runs/rnn_hidden_128_comparison/figures/prediction_examples.png)

图 3 展示隐藏维度变化带来的准确率、参数量和耗时差异；图 4 给出最佳 RNN 的测试集
预测示例，用于检查单样本推理结果是否与总体指标一致。

## 5. 实验总结

本实验理解了二维图片如何转换为序列、隐藏状态如何逐步传递历史信息，以及最后时间步
如何用于分类。结果证明隐藏维度会影响模型容量和准确率，同时也提醒我们区分准确率
结论与容易受运行环境影响的计时结论。

# 总结

两个实验都采用自行搭建模型、固定数据划分和单变量对比。CNN 实验重点理解空间特征
提取，RNN 实验重点理解序列状态传递。通过记录训练曲线、混淆矩阵、预测示例、硬件和
效率指标，实验结果能够被复现并用于课堂讲解。
