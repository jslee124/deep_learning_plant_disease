# 实验一阶段三说明：规范化对比实验

## 1. 这一阶段完成了什么

本阶段把原来的“能训练一次”升级为“可以规范地重复做对比实验”：

- Kaggle 数据集的 `train` 继续作为训练集。
- 带标签的 `valid` 按类别和固定随机种子拆成验证集、独立测试集。
- 每次训练使用唯一实验名称，模型、曲线和日志保存到独立目录。
- 自动记录数据量、训练参数、硬件环境、准确率和训练效率。
- CNN 支持配置卷积核大小和卷积块数量。

## 2. 为什么这样设计

验证集用于选择最佳模型，测试集只用于训练结束后的最终评价。如果同一批图片同时
承担验证和测试，测试准确率会间接参与模型选择，不能客观反映泛化能力。

对比实验还要求控制变量。比较 `3x3` 和 `5x5` 卷积核时，Epoch、数据划分、随机
种子、优化器、学习率和卷积块数量都应保持一致，只修改卷积核大小。

## 3. 关键输入输出

输入图片张量形状为 `[batch_size, 3, H, W]`。默认 4 个卷积块的通道数依次为
32、64、128、256。自适应平均池化后张量形状为 `[batch_size, 256, 1, 1]`，
经过全连接层后输出 `[batch_size, 38]`，38 个数分别是各病害类别的原始得分。

默认数据划分：

- 训练集：70,295 张。
- 验证集：8,790 张。
- 独立测试集：8,782 张。
- 类别数：38。

## 4. 参数变化的影响

- `kernel_size=3`：参数量较少，更偏向提取局部细节，计算速度通常更快。
- `kernel_size=5`：单层感受野更大，但参数量和计算量明显增加。
- `conv_blocks` 增加：模型可以逐层组合更高级特征，但训练更慢，也可能更容易过拟合。
- 当前 4 卷积块、3x3 卷积核模型约有 427,174 个可训练参数。
- 保持其他条件不变时，4 卷积块、5x5 卷积核模型约有 1,116,838 个可训练参数。

## 5. 老师可能会问什么

**为什么不能直接把 valid 当 test？**

验证集已经用于选择最佳 Epoch。如果再把它报告成测试结果，相当于模型选择和最终
评价看了同一份数据，结果会偏乐观。

**为什么拆分时要按类别进行？**

按类别拆分能让验证集和测试集都保留相近的类别比例，避免某些类别偶然集中到一边。

**为什么 5x5 卷积参数更多？**

卷积参数量与卷积核面积成正比。其他条件相同时，单个输入输出通道对中，3x3 有
9 个权重，5x5 有 25 个权重。

**怎样保证比较公平？**

两次实验使用相同数据划分、随机种子、Epoch、Batch Size、学习率、优化器和网络
通道数，只修改卷积核大小。

## 6. 建议运行命令

```bash
python experiment_1_cnn/src/train.py --experiment-name kernel_3x3 --kernel-size 3
python experiment_1_cnn/src/train.py --experiment-name kernel_5x5 --kernel-size 5
```

运行后重点比较：

- 最佳验证集 Accuracy。
- 独立测试集 Accuracy 和 Loss。
- 总训练时间、平均每个 Epoch 时间、每秒处理样本数。
- 模型参数量。
- 训练集与测试集准确率差距。
