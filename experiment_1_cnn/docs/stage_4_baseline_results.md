# 实验一阶段四：3x3 CNN 正式基线结果

## 1. 本阶段完成了什么

使用新规范完成 `3x3` 卷积核 CNN 的正式基线训练、验证和独立测试。实验名称为
`cnn_kernel_3x3_baseline_v2`，所有模型、日志和图表保存在该实验的独立输出目录中。

训练脚本还增加了逐轮训练历史、`latest_checkpoint.pth` 和 `--resume`。训练意外中断时，
可以从最近完成的 Epoch 继续，而不需要从第 1 轮重新开始。

## 2. 实验配置

| 参数 | 值 |
| --- | --- |
| 输入尺寸 | 224x224 |
| 卷积核 | 3x3 |
| 卷积块数量 | 4 |
| Batch Size | 32 |
| Epoch | 10 |
| 优化器 | Adam |
| 学习率 | 0.001 |
| Dropout | 0.3 |
| 数据增强 | 开启 |
| 随机种子 | 42 |
| DataLoader Workers | 4 |
| 可训练参数量 | 427,174 |
| 训练设备 | NVIDIA GeForce RTX 4060 Laptop GPU |

数据包含 70,295 张训练图片、8,790 张验证图片和 8,782 张独立测试图片，共 38 类。
验证集和测试集由原始带标签 `valid` 按类别、固定随机种子拆分，测试集不参与模型选择。

## 3. 实验结果

| 指标 | 结果 |
| --- | --- |
| 最佳 Epoch | 9 |
| 最佳验证 Loss | 0.1873 |
| 最佳验证 Accuracy | 93.96% |
| 独立测试 Loss | 0.1863 |
| 独立测试 Accuracy | 94.02% |
| 总训练时间 | 1,560.47 秒，约 26.01 分钟 |
| 平均每 Epoch 时间 | 156.02 秒 |
| 平均训练吞吐量 | 450.47 张/秒 |

第 10 轮训练 Accuracy 继续上升到 82.09%，但验证 Accuracy 从第 9 轮的 93.96% 回落到
89.68%。因此最终测试使用第 9 轮保存的最佳模型，而不是直接使用最后一轮模型。

训练 Accuracy 低于验证和测试 Accuracy 并不表示计算错误。训练阶段使用了随机旋转、
翻转等数据增强和 Dropout，样本更难且部分神经元会随机失活；验证和测试阶段关闭这些
随机扰动，因此准确率可能更高。

## 4. 为什么增加 DataLoader Workers

第一次正式运行使用 `num_workers=0`，约 60 分钟仍未完成。改为 4 个 Worker 后，图片读取
和预处理可以与 GPU 计算并行，完整实验约 26 分钟完成。`3x3` 与后续 `5x5` 实验必须都
使用 4 个 Worker，才能公平比较训练效率。

## 5. 老师可能会问什么

**为什么保存最佳模型，而不是最后一轮模型？**

验证集表现可能在后期波动甚至下降。本实验第 9 轮验证 Accuracy 为 93.96%，第 10 轮降至
89.68%，所以使用验证集选择出的第 9 轮模型更合理。

**测试集在训练中起什么作用？**

测试集不更新参数，也不用于选择最佳 Epoch。完成模型选择后，只用测试集做一次最终评价，
这样更能反映模型对未参与训练和选择的数据的泛化能力。

**`num_workers` 会改变模型准确率吗？**

它主要改变数据读取效率，不改变网络结构、损失函数和优化规则。对比实验仍要保持相同
Worker 数量，避免训练时间比较受到数据加载设置影响。
