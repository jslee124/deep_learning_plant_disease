# 实验一阶段五：卷积核对比与特征图可视化

## 1. 实验目的

在其他条件完全相同的情况下，只把 CNN 卷积核从 `3x3` 改为 `5x5`，比较准确率、
训练效率、参数量和泛化差距。同时将每个卷积层的输出可视化，观察图片经过卷积处理后
发生的变化。

## 2. 控制变量

两组实验都使用 4 个卷积块、224x224 输入、10 Epoch、Batch Size 32、Adam、学习率
0.001、Dropout 0.3、相同数据增强、随机种子 42 和 4 个 DataLoader Worker。训练集、
验证集、测试集及训练硬件也完全相同，唯一主动改变的变量是卷积核大小。

| 实验名称 | 卷积核 |
| --- | ---: |
| `cnn_kernel_3x3_baseline_v2` | 3x3 |
| `cnn_kernel_5x5_comparison` | 5x5 |

## 3. 对比结果

| 指标 | 3x3 | 5x5 |
| --- | ---: | ---: |
| 最佳 Epoch | 9 | 9 |
| 最佳验证 Accuracy | 93.96% | 95.16% |
| 独立测试 Accuracy | 94.02% | 95.05% |
| 可训练参数量 | 427,174 | 1,116,838 |
| 总训练时间 | 1,560.47 秒 | 2,183.73 秒 |
| 平均每 Epoch | 156.02 秒 | 218.33 秒 |
| 训练吞吐量 | 450.47 张/秒 | 321.90 张/秒 |
| 验证-测试泛化差距 | 0.063 个百分点 | 0.118 个百分点 |

`5x5` 的测试 Accuracy 比 `3x3` 高 1.02 个百分点，说明在当前植物病害数据集和模型
结构下，更大的单层感受野有助于同时观察病斑及其周围纹理。但 `5x5` 的参数量是
`3x3` 的 2.61 倍，平均每 Epoch 时间增加 39.94%，吞吐量下降 28.54%。因此它取得了
更高准确率，但计算成本也明显增加，不能只根据 Accuracy 判断其绝对更优。

这里将“泛化差距”定义为最佳验证 Accuracy 与独立测试 Accuracy 的绝对差。两组差距
都小于 0.12 个百分点，说明通过验证集选出的模型在未参与模型选择的测试集上表现稳定。
训练 Accuracy 使用随机数据增强和 Dropout，而且记录自最后一个 Epoch，不适合与最佳
模型的测试 Accuracy 直接计算同口径差距。

自动汇总产物位于：

```text
experiment_1_cnn/outputs/comparisons/
  cnn_kernel_3x3_baseline_v2_vs_cnn_kernel_5x5_comparison/
```

其中包含 `comparison.csv`、`comparison.json`、`comparison.md` 和 `comparison.png`。

## 4. 特征图可视化结果

可视化脚本使用 forward hook 读取最佳模型四个 `Conv2d` 层的输出，不改变模型参数。
同一张测试图片在两组模型上都被正确识别为 `Apple___Apple_scab`：

| 模型 | 预测置信度 |
| --- | ---: |
| 3x3 | 99.10% |
| 5x5 | 99.62% |

各层输出张量形状如下：

| 卷积层 | 输出形状 |
| --- | --- |
| 第 1 层 | `[1, 32, 224, 224]` |
| 第 2 层 | `[1, 64, 112, 112]` |
| 第 3 层 | `[1, 128, 56, 56]` |
| 第 4 层 | `[1, 256, 28, 28]` |

第一层仍能清晰看到叶缘、叶脉和病斑等局部纹理。经过池化和更深的卷积后，空间分辨率
逐步降低，单个像素不再对应原图的细小细节，响应逐渐集中到叶片轮廓和具有判别作用的
区域。这说明浅层更偏向提取边缘和纹理，深层会组合浅层信息形成更抽象的病害特征。

特征图保存在两组实验各自的 `figures/feature_maps_sample_0.png`，对应 JSON 文件记录
真实类别、预测类别、置信度和每层输出形状。

## 6. 老师可能会问什么

**为什么 5x5 参数量更多？**

卷积层每个输入输出通道组合所需权重与卷积核面积成正比。`3x3` 有 9 个权重位置，
`5x5` 有 25 个，所以在通道数相同时参数量和计算量都会明显增加。

**为什么要保持 padding？**

两种卷积都使用 `padding=kernel_size//2`，使卷积前后高宽不变。这样更换卷积核不会
额外改变特征图尺寸，对比更接近单变量实验。

**为什么后面的特征图越来越模糊？**

池化会逐步降低空间分辨率，同时深层神经元具有更大的感受野。深层关注的是组合后的
类别相关特征，不再追求还原每个原始像素，所以看起来更抽象。

**这次实验能证明 5x5 一定比 3x3 好吗？**

不能。当前结果只说明在这份数据、这次模型结构和随机种子下，`5x5` 准确率更高。
严格研究还应重复多次并报告均值和标准差。本课程实验主要用于展示控制变量、参数影响
和结果解释。
